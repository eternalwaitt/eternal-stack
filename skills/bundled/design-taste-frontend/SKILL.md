# Marketing and portfolio design

Use for landing pages, portfolios, and marketing redesigns. Preserve the brief, existing brand assets, accessibility needs, and approved direction. Product dashboards and ordinary component fixes use the project's established design system instead.

1. Establish the page's audience, job, content and constraints from the request and current work. Ask only about material unresolved choices; do not make the user tune design dials.
2. Choose a deliberate visual direction and implement the full authorized scope. Exploration and generated imagery are useful when they resolve a visual question, not mandatory gates for an already supplied direction.
3. Read only the relevant sections of the preserved [design guide](references/design-guide.md), using its headings to select a bounded excerpt. Do not load the whole catalog by default.
4. Verify responsive behavior, keyboard focus, reduced motion, content truth and the actual interaction. A screenshot is visual evidence, not functional proof.
