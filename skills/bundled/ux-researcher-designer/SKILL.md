# UX Researcher & Designer

Comprehensive toolkit for user-centered research and experience design.

## Core Capabilities
- Data-driven persona generation from user data and interviews
- Customer journey mapping
- Usability testing frameworks
- Research synthesis and insights
- Design validation methods

## Persona Generation

When creating personas from user data or interview notes:
- Analyze user behavior patterns and segment by goals, not demographics alone
- Identify persona archetypes with clear motivations and pain points
- Extract psychographics and context-of-use scenarios
- Generate realistic scenarios and task flows
- Derive design implications for each persona
- Note confidence level based on sample size and data quality

## Journey Mapping

Map the end-to-end user journey including:
- Touchpoints, channels, and actors
- User actions, thoughts, and emotions at each stage
- Pain points and moments of truth
- Opportunities for improvement

## Usability Testing

Apply structured testing frameworks:
- Define tasks aligned to critical user goals
- Prepare moderation scripts and success criteria
- Capture qualitative and quantitative metrics
- Synthesize findings into prioritized recommendations

## Research Synthesis

Consolidate research into actionable insights:
- Affinity mapping of observations
- Pattern identification across sessions
- Hypothesis validation or invalidation
- Recommendations tied to specific design decisions
